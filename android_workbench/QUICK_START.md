# 最快方案：使用在线工具生成 APK

## 方案一：使用 AppMySite（最简单）

1. 访问 https://appmysite.com
2. 点击 "Get Started Free"
3. 选择 "Website to App" 模式
4. 提供你的 Web 应用文件（上传 `assets/www/` 中的文件）
5. 配置应用名称和图标
6. 下载生成的 APK

## 方案二：使用 GoNative

1. 访问 https://gonative.io
2. 注册账号
3. 创建新项目
4. 上传 `assets/www/` 中的所有文件
5. 自定义应用设置
6. 下载 APK

## 方案三：使用 WebViewGold

1. 访问 https://webviewgold.com
2. 输入应用信息
3. 上传 Web 文件
4. 生成并下载 APK

## 注意

这些在线工具通常需要付费或有试用期。如果需要免费方案，请回到 README.md 中的本地构建方法。
